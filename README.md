Sunflower Parks & Gardens - Static site

Files:
- index.html, about.html, properties.html, iri.html, contact.html
- css/style.css
- js/slider.js
- images/ (place hero and project images here)

How to run:
Open `frontend/index.html` in your browser. The slideshow uses images placed in `frontend/images/` named `slide1.jpg`, `slide2.jpg`, and `slide3.jpg` by default.

Notes:
- Brand colors: white and a stylish yellow (CSS variable `--brand`).
- Replace images in the `images/` folder with project photos or aerial views.
